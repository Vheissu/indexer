# Feeds from Common Crawl that are still active, proposed by `indexer survivors`.
#
# The weekly survivors workflow scans a crawl from about 5 years ago, checks every feed it
# advertised, and appends the ones that pass (an item with a real tag in the last 8 months,
# labelled English, served over https today) to this file in a pull request. To review it,
# delete the URL line of any feed you don't want (its comment lines can stay or go), then merge.
# The daily input job loads every URL here into the inputs table.
#
# Each entry: title · language · date of the newest tagged item · tags, then the Common Crawl
# WAT file it was found in, then the feed URL. Titles and tags come from the feeds themselves.
# Common Crawl terms of use: https://commoncrawl.org/terms-of-use
